# Hämar – käsitöö küünalde veebipood

## 1. Projekti nimi

**Hämar – käsitöö küünalde tutvustus- ja müügileht.**

## 2. Eesmärk

Projekti eesmärk on luua väike veebipood, kus saab tutvuda käsitsi valmistatud küünaldega ja esitada tellimuse soovi. Veebileht aitab küünalde valmistajal oma tooteid tutvustada ning ostjal leida sobiva lõhna ja küünla.

## 3. Sihtgrupp

Veebileht on mõeldud inimestele, kes otsivad koju hubasust, soovivad osta käsitöötooteid või otsivad kingitust. Samuti sobib see väikesele küünalde valmistajale, kes soovib oma tooteid internetis esitleda.

## 4. Funktsionaalsus

Kasutaja saab veebilehel:

1. Vaadata küünalde valikut, hindu ja lõhnakirjeldusi.
2. Lugeda küünalde valmistamise ja ettevõtte kohta.
3. Lisada küünlaid ostukorvi.
4. Muuta ostukorvis toodete koguseid ja näha ostukorvi summat.
5. Koostada ostukorvi põhjal tellimuse e-kirja.
6. Liikuda lehe eri osade vahel menüü kaudu.
7. Sisestada e-posti aadressi uudiskirjaga liitumiseks (vormi ühendamine uudiskirja teenusega on hilisem täiendus).

## 5. Tehnoloogiad

- **HTML** – veebilehe sisu ja struktuur.
- **CSS** – kujundus ja eri ekraanisuurustele kohanduv paigutus.
- **JavaScript** – toodete kuvamine, ostukorvi toimingud ja tellimuse e-kirja koostamine.
- **GitHub** – projekti failide hoidmine ja versioonide jälgimine.
- **GitHub Pages** – veebilehe avaldamine internetis.

## 6. Teostusplaan

1. Kavandada veebilehe sisu, värvid ja paigutus.
2. Koostada HTML-iga lehe põhiosad: avaleht, tooted, tutvustus ja kontakt.
3. Kujundada leht CSS-iga ning kohandada see telefonile ja arvutile.
4. Lisada JavaScriptiga toodete kuvamine ja ostukorvi funktsioonid.
5. Lisada tellimuse e-kirja koostamise võimalus.
6. Kontrollida lehe toimimist eri ekraanisuurustel ja parandada leitud vead.
7. Hoida projekt GitHubi repositooriumis ning avaldada see GitHub Pagesi abil.

## 7. Valmimise kriteeriumid

Projekt on valmis, kui veebilehel on küünalde tutvustus ja vähemalt kolm toodet koos nimede, hindade ning lõhnakirjeldustega; kasutaja saab tooteid ostukorvi lisada, koguseid muuta ja summat näha; tellimuse e-kirja koostamine töötab; leht on loetav nii telefonis kui ka arvutis; ning projekti README sisaldab plaani ja GitHubi repositooriumis on vajalikud failid.
